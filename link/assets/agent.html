Muse Link エージェント

土台フォルダ: C:\MuseWorkspaces / 専用ユーザー: muselink

Muse Link は連携専用の別アプリです（Museアプリ本体とは別に動きます）。このウィンドウを閉じてもエージェントはトレイに常駐します。停止するときは一番下の「Muse Linkを停止する」か、トレイの右クリックメニューから「Quit Muse Link」を選んでください。

設定

エージェントの起動・停止は、Muse本体アプリのプラグインページで管理します。本体アプリが起動している間だけエージェントも動作し、本体を終了するとエージェントも終了します。

作業はチャットごとに紐づけたフォルダの中だけです。紐づけのないチャットではPCに触りません。

連携を止める

エージェントを終了します。接続の土台（鍵・専用ユーザー・土台フォルダ）は残るので、次に起動すればそのまま再開できます。

Museの公開鍵を削除し、専用ユーザー muselink を無効化します。土台フォルダの中身、Tailscale、OpenSSH自体は残ります。UACが1回出ます。

アプリを削除します。既定はおすすめ方式です（アプリ・専用ユーザー・鍵を消し、作業ファイルとTailscale / OpenSSHは残す）。アンインストール前に上の「鍵を無効化」を実行すると確実です。
