# Muse Windows プラグイン作成キット

Muse Windows 本体アプリ用のプラグインを作るためのサンプル一式です。

## まず試す

1. 本体アプリを起動し、メニュー「プラグイン」→「プラグイン管理を開く」
2. 「plugins フォルダを開く」から、アプリの実行フォルダにある `plugins` フォルダを開く
3. このキットの `example-plugin` フォルダを `plugins` フォルダにコピーする
4. プラグイン管理ページに「Example Plugin」が出てくる（exe はダミー名なので、起動は自分のプログラムに差し替えてから）

## 自分のプラグインを作る

`example-plugin` をコピーして名前を変え、`muse-plugin.json` を書き換え、`exe` に自分のプログラムのファイル名を指定します。仕様の詳細は `example-plugin/README.md` を見てください。

## 配布する

- プラグインのフォルダの「中身」を zip にして（フォルダごと圧縮しないこと）、GitHub Releases などに置きます
- 更新フィード（yml）を用意すると、本体アプリが新版を検出して、プラグイン管理ページからアップデートできるようになります
